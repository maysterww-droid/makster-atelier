# Known Limits — 2.3

- CAD panels are derived rectangular structural projections, not arbitrary B-rep/free-form solids.
- True one-piece corner cabinets, angled carcasses and polygonal custom furniture still need dedicated Engineering rule packs.
- Snapping currently targets room walls and neighbouring furniture edges; obstacle snapping is not yet a manufacturing constraint solver.
- Collision detection is 2D plan AABB warning logic and intentionally does not silently resolve collisions.
- 3D remains lightweight axonometric, not photoreal PBR.
- Broad beta still requires validation on 20–30 anonymized real jobs with zero critical dimension errors.
