# Pro Source Merge Notes 2.5

The merge was performed selectively, not by embedding the old Flutter calculator as a second application.

Useful concepts recovered from the Makster Pro / Makster Calculator lineage included kitchen section types, section-specific dimensions, Gola/push-to-open intent, worktop/plinth/leg concepts, drawer system choice, front split/material concepts, four-side edging/grain concepts and neutral drilling/DXF export thinking.

The current Makster Core already had stronger deterministic Blum Engineering and Manufacturing Data Trust than the old prototypes. Therefore old demonstration drilling coordinates and local price calculations were intentionally discarded as authority.

The historical Makster Pro 5.1 Library object is retained as a product/UI reference, but 2.5 production logic is based only on normalized ProjectModel data and the current trusted Engineering pipeline.
