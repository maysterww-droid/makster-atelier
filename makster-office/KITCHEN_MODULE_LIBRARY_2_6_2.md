# Makster AI 2.6.2 — Kitchen Module Library

Kitchen sections are now backed by stable library module identifiers instead of being only one-off descriptions.

## Library families
- Base: storage, drawers, sink, oven+hob, dishwasher, open.
- Wall: storage, hood, open.
- Tall: pantry, oven, fridge, open.
- Technical: base, wall, tall.

## Trust rule
The library supplies deterministic construction defaults. Explicit project values always win. Appliance envelopes, cutouts, hardware machining profiles and measured site-fit facts are never invented by a template.

R14 lower run is mapped to library IDs and compiled through the same Engineering Engine. R14 site-fit and GTV Modern Slide rules remain authoritative.
