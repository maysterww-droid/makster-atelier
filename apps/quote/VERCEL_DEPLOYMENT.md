# Makster Quote — Vercel deployment

Makster Quote is deployed as a dedicated Vercel project, separate from the marketing website.

- Vercel project: `makster-quote-app`
- Git branch: `makster-quote-0.1-core`
- Root Directory: `apps/quote`
- Framework Preset: `Next.js`

The marketing website uses its own Vercel project and must not override these settings.
