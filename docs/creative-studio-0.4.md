# Creative Studio 0.4 — dry-run milestone

Fixture `MAK-CR-0001` is the first zero-credit Makster Atelier commercial project. It defines a 15-second Czech-market Meta/Instagram concept and deliberately contains no fabricated product references. Real Module Library / Blender / Dream Planner assets will be attached only after provider/data adapters are connected.

Automatic QA now blocks cross-brand contamination, unapproved assets, missing selected takes, product drift, continuity errors, bad typography, obvious AI artifacts, unsupported claims and invented UI. Standard exports are planned as 9:16, 1:1 and 16:9. CostLedger tracks total and accepted generation cost per project/brand/currency.

No external generator is called in this milestone, so this dry run consumes zero provider credits.
